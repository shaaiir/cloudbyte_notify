# Cloudbyte Notify

A modern, responsive countdown landing page for Cloudbyte featuring custom character color countdown cards, smooth flip animations, and interactive email subscription.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Vanilla CSS
- **Icons & UI**: Lucide React + Framer Motion
- **Fonts**: Outfit, Inter, Fira Code

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```
