# Cloudbyte Notify Landing Page & Secret Admin Dashboard

A high-converting, responsive countdown landing page for Cloudbyte with an integrated secret admin dashboard.

## 🚀 Live Production URLs

Landing Page**: [https://cloudbyte-notify.shahirtzo7.workers.dev](https://cloudbyte-notify.shahirtzo7.workers.dev)




## ✨ Features
- **4 Character Color Countdown Cards**: Cyan (Days), Brown (Hours), Orange (Minutes), Royal Blue (Seconds) with broken corner SVG chips and 3D flip animation.
- **Side-by-Side Responsive Layout**: Video banner and Email signup card on laptop/desktop; stacks vertically on mobile devices.
- **Strict Email Security Validation**: Real-time validation and sanitization.
- **In-Button Loading Spinner**: Animated circular loading spinner on subscription submit.
